# Automobile Sales Analytics Dashboard

## Project Overview

This project presents an interactive Automobile Sales Analytics Dashboard developed using Microsoft Power BI. The dashboard analyzes Tata Motors automobile sales data and provides insights into sales volume, revenue, vehicle models, pricing, regional performance, fuel types and financing patterns.

## Objectives

- Analyze automobile sales performance
- Compare vehicle models
- Analyze regional and state-wise sales
- Study pricing and sales volume
- Analyze fuel-type and body-type distribution
- Examine financing patterns

## Dataset

Dataset: Tata Motors Automobile Sales Dataset

Records: 100,000

Original Attributes: 71

Selected Attributes: 21

## Dashboard Pages

### 1. Executive Sales Dashboard

- Total Units Sold
- Total Revenue
- Average Selling Price
- Total Models
- Average Mileage
- Sales Trend
- Sales by Region
- Top 10 Models by Sales
- Sales by Fuel Type

### 2. Brand & Model Analysis

- Sales by Model
- Revenue by Model
- Average Selling Price by Model
- Price vs Sales Volume
- Year, Fuel Type and Model filters

### 3. Regional & Customer Analysis

- Sales by Region
- Sales by State
- Finance vs Non-Finance Sales
- Sales by Bank
- Average EMI by Region
- Sales by Body Type
